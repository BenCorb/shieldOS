# local/ — your own Shield, kept out of git

`local/` is gitignored as a whole. Everything that describes *your* setup lives there, so the
repository stays shareable and you can still drive your own Shield from the same checkout.

```bash
mkdir -p local
cp shieldos/local.example/shield.env.example local/shield.env      # then set your Shield's IP
cp shieldos/local.example/theme.json local/theme.json # then set your dock
shieldos/wallpaper.sh ~/Pictures/my-photo.jpg                       # writes local/wallpaper.jpg
shieldos/apply.sh --dry-run                                         # check the merged config
shieldos/apply.sh                                                   # push it to the Shield
```

Suggested layout (only `shield.env` and `theme/` are read by the scripts):

| Path | What |
|---|---|
| `local/shield.env` | `TV_HOST=<shield ip>` |
| `local/theme.json` | your overrides on top of `shieldos/theme.json` (dock apps, wallpaper keys…) |
| `local/wallpaper.jpg` | your wallpaper, or `local/wallpapers/` for a rotating set |
| `local/build/` | generated by `apply.sh`, safe to delete |
| `local/backup/` | dumps from `tools/manage.py backup` or `adb shell pm list packages` before changes |
| `local/debloat/` | your own debloat lists, if they differ from `examples/nvidia-shield-tv-pro-2019/` |
| `local/apks/` | sideloaded APKs you keep around (with their SHA-256) |
| `local/notes/` | what you changed on the box and why |

Never move anything from here into a tracked folder without checking it for IPs, serials, account
names, app choices or photos first.
